# `ui/` — the PrismDMX interface

React and TypeScript over Vite. It is the desk: the canvas, the windows, the
executor and encoder bars, the command line and the settings window. It holds no
state of its own — everything it draws comes from `prismd` over the protocol in
[`docs/IPC_PROTOCOL.md`](../docs/IPC_PROTOCOL.md), which is decision **D3**.

The repository's [README](../README.md) has the installation, the basics and the
closed-beta process. This file is the two or three things that are only true in
here.

## `src/bindings/` is generated, not written

It comes out of Rust — `prism_domain`'s types through `ts-rs` — and it is **not
committed**. Nothing typechecks until it exists:

```bash
cargo test -p prism-domain
```

That also writes `src/bindings/variants.ts`, the run-time tables a decoder
narrows a string with, read back out of the very unions it generated. A binding
therefore cannot go stale: it is regenerated by the same command that tests the
types.

## The two suites, and they run one at a time

```bash
npm run test
```

```bash
npm run e2e
```

The first is `vitest` in jsdom, with no socket anywhere: the transport and the
clock are arguments, so a five-second reconnect backoff is *asserted* rather than
waited for. The second is Playwright against a real `prismd --mock-output`, which
it starts and kills itself, because *the daemon goes away and the interface comes
back* is a claim about a process.

**Run them one at a time**, and not beside `cargo test --workspace` or a
`tauri build`. Both suites measure something — the telemetry frame budget, the
render count — and a busy machine makes them fail in a way that looks exactly
like a regression.

## Where the desktop shell fits

The interface runs in two places: inside `crates/prism-app`, and in an ordinary
browser. [`src/shell/bridge.ts`](src/shell/bridge.ts) is the whole of the
difference — the file dialogues and the autostart entry, each answering *there is
no shell* rather than throwing, so every panel works in both. Nothing else in
here knows which one it is in.
